# Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is a comprehensive cloud computing platform provided by Amazon. Launched in 2006, it offers over 200 fully-featured services from data centers globally.

## Global Infrastructure
- **Regions**: 31 geographic regions worldwide
- **Availability Zones**: 99+ availability zones
- **Edge Locations**: 400+ edge locations for content delivery

## Cloud Management Console
AWS Management Console is a web-based interface for accessing and managing AWS services. It provides a unified dashboard for monitoring resources, configuring services, and managing billing.

## Four Core Services

### 1. Amazon EC2 (Elastic Compute Cloud)
Provides scalable virtual servers (instances) for running applications.

### 2. Amazon S3 (Simple Storage Service)
Object storage service offering industry-leading scalability, data availability, security, and performance.

### 3. Amazon VPC (Virtual Private Cloud)
Creates a logically isolated section of the AWS cloud where you can launch AWS resources in a virtual network.

### 4. AWS IAM (Identity and Access Management)
Manages access to AWS services and resources securely.

## Three Advantages
1. **Market Leadership**: Largest market share and most extensive service portfolio
2. **Global Reach**: Most extensive global infrastructure
3. **Mature Ecosystem**: Extensive third-party integrations and community support

## Typical Enterprise Use Cases
- Web hosting and content delivery
- Big data processing and analytics
- Enterprise applications (SAP, Oracle)
- Machine learning and AI workloads
- Backup and disaster recovery
